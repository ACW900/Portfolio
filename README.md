# Alex Wiemer · Portfolio

My portfolio site, hosted for free on GitHub Pages: **https://acw900.github.io/Portfolio/**

It's plain HTML and CSS (`index.html` + `styles.css`), with no build step. Projects are listed newest first, each linking to its code or a live site.

## Updating it

1. Edit `index.html` (each project is one `<article class="card">` block, newest at the top).
2. Commit and push to `main`. GitHub Pages republishes the site within a minute or two.
